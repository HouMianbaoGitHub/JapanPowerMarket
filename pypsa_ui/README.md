# 日本 9 区域电力市场 PyPSA 交互界面

基于 [PyPSA](https://pypsa.org) + [Streamlit](https://streamlit.io) 的程式化经济调度模型。
在浏览器里调参数 → PyPSA 用 HiGHS 求解 → 实时看到区域电价、发电结构、联络线阻塞。

## 运行

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 可调参数
- 季节 / 模拟天数（1–14 天，逐小时）
- LNG、煤炭、原油价格，汇率，碳价 → 自动换算火电边际成本
- 需求倍数、光伏/风电装机倍数、火电最低出力比例
- 各区域核电可用率
- 联络线容量倍数、东西变频站 (FC) 容量、切负荷价格

## 输出
- 地图：区域平均电价 + 联络线利用率/阻塞
- 价格时序与价格持续曲线
- 发电结构堆叠图（全国或单区域）
- 联络线潮流与区域间价差
- 多情景对比（例如 LNG 价格冲击对各区域批发电价的影响）
- CSV 导出（长表格式，可直接 `import delimited` 进 Stata）

## 文件
| 文件 | 内容 |
|---|---|
| `data.py` | 区域、装机、联络线等假设（**示意值**，请替换为 OCCTO 等真实数据） |
| `model.py` | 构建并求解 PyPSA 网络；`python model.py` 可脱离 UI 单独运行 |
| `app.py` | Streamlit 界面 |

## 模型说明与局限
- 区域间用双向 Link（运输模型），区域内无网络约束；区域电价 = 节点影子价格。
- 每种火电拆为 3 个效率档形成阶梯供给曲线；纯线性规划，无机组组合/爬坡约束。
- 需求、光伏、风电曲线为合成数据（固定随机种子）。
- 结果用于直觉与情景比较，不代表 JEPX 实际价格。
